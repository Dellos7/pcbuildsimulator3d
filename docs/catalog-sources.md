no productos comerciales. Las GPU usan un perfil común HDMI/DisplayPort; algunas

El resto de los valores del catálogo previo no se ha actualizado como una lista
de compra actual. La estimación de potencia combina valores orientativos; no es
una medición de consumo ni una garantía de estabilidad.
